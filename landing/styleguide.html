Quick start: adaptasi ke project lain

1. Salin folder css/ dan js/. Muat CSS berurutan: tokens → base → components → sections → animations. Muat GSAP + ScrollTrigger dari CDN, lalu js/animations.js.
2. Ganti brand hanya di css/tokens.css (warna, font, radius, timing). Tidak ada nilai hard-coded di komponen.
3. Tambahkan atribut data-anim="fade-up" (dan teman-temannya) ke elemen mana pun, lalu panggil Anim.init(). Tidak perlu menulis JS animasi.
4. Hapus/ganti css/sections.css dan bagian hero di index.html sesuai kebutuhan. Engine & komponen tetap jalan.

08

Lapisan ilustrasi hero

Ilustrasi hero adalah 7 lapisan SVG inline (tanpa file gambar) di dalam .hero__scene. Setiap lapisan punya data-hero-layer="kecepatan" (parallax scroll, dikontrol main.js) dan SVG-nya punya data-depth (parallax kursor). Untuk memakai gambar sendiri, ganti isi <svg> dengan <img> berukuran 1440×900 dan atribut yang sama.

  1. Siluet kota — gedung, menara pendingin, crane (putih transparan). data-hero-layer="0.55" · data-depth="0.005" · paling lambat
  2. Gunung jauh — gradien abu-kebiruan dengan garis striasi. data-hero-layer="0.42" · data-depth="0.009"
  3. Gunung dekat — lebih gelap + petak rumput kuning. data-hero-layer="0.3" · data-depth="0.013"
  4. Turbin angin — 4 turbin; bilah berputar via GSAP ([data-turbine="durasi"]), dipercepat saat scroll cepat. data-hero-layer="0.24" · data-depth="0.015"
  5. Perbukitan teal — dengan petak kuning. data-hero-layer="0.18" · data-depth="0.018"
  6. Ladang, tiang listrik, rumah panel surya — rumah memakai <use href="#house"> sehingga mudah ditambah. data-hero-layer="0.1" · data-depth="0.022"
  7. Semak & bunga latar depan — bunga bergoyang (data-sway), serbuk melayang. Nilai negatif = bergerak berlawanan (lebih cepat dari scroll). data-hero-layer="-0.12" · data-depth="0.03" · paling cepat
<!-- pola satu lapisan; tambah/kurangi sesuka hati --> <div class="hero__layer" data-hero-layer="0.3"> <svg data-depth="0.013" viewBox="0 0 1440 900" preserveAspectRatio="xMidYMax slice"> … </svg> </div>

API JavaScript

Anim.init(); Anim.init(document.querySelector('#modal')); // mainkan ulang reveal elemen sekarang (untuk demo / konten dinamis) Anim.preview(el); // hitung ulang posisi setelah konten berubah (accordion, tab, fetch) Anim.refresh(); // tambah preset sendiri sebelum init ('D' = kelipatan --anim-distance) Anim.presets['swing'] = { from: { opacity: 0, rotation: -12, y: '+=D', transformOrigin: '0% 0%' }, ease: 'back.out(1.6)' }; // React / Vue / Next: panggil di effect setelah mount, refresh saat route berubah useEffect(() => { Anim.init(ref.current); return () => ScrollTrigger.getAll().forEach(t => t.kill()); }, []);

Prinsip motion

Lakukan

  • Satu arah gerak per section (mis. semua fade-up) agar terasa tenang.
  • Stagger 0.06–0.15s; lebih dari 6 item, kecilkan jeda.
  • Durasi 0.6–1.2s dengan expo.out untuk reveal; back.out untuk elemen kecil (badge, tombol).
  • Parallax lapisan jauh lebih lambat dari lapisan dekat.
  • Hormati prefers-reduced-motion — sudah otomatis.
  • Pakai ?noanim saat memeriksa layout.

Hindari

  • Menggabungkan animasi CSS transform (data-float) dan GSAP (data-anim) pada elemen yang sama.
  • Lebih dari 3 preset berbeda dalam satu viewport.
  • Split chars pada paragraf panjang (berat & sulit dibaca).
  • Parallax pada teks utama yang harus dibaca.
  • Animasi yang menggeser layout (gunakan transform/opacity saja).
